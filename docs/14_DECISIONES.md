# Decisiones del proyecto

## DEC-001 - React

Se utiliza React en lugar de Next.js porque el proyecto es exclusivamente un prototipo frontend SPA.

## DEC-002 - TypeScript

Todo el código será TypeScript.

## DEC-003 - Vite

Se utilizará Vite como herramienta de construcción y desarrollo.

## DEC-004 - Bootstrap

Se utilizará Bootstrap 5 para la interfaz.

## DEC-005 - Sin backend

No existe backend.

## DEC-006 - Sin base de datos

No existe base de datos.

## DEC-007 - Mock

Todos los datos serán simulados.

## DEC-008 - Login simulado

El login se implementará únicamente para poder demostrar diferentes perfiles y flujos.

## DEC-009 - Emails simulados

El sistema simulará las notificaciones por email.

## DEC-010 - Servicios mock

Se utilizará una capa de servicios para evitar que los componentes dependan directamente de los datos mock.

## DEC-011 - Coincidencias

Las coincidencias se mostrarán como información para el administrador.

No se implementará un rechazo automático.

## DEC-012 - Planificación rechazada

Una planificación rechazada permanece como histórico y permite crear una nueva planificación.

## DEC-013 - Tabla no utilizada

La relación `RelacionUserAprobadorUsers` queda explícitamente fuera de la lógica del prototipo.

## DEC-014 - Simplicidad

No se incorporarán soluciones de arquitectura o dependencias que no sean necesarias para demostrar el prototipo.
