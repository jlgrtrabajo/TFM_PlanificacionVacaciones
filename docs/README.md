# Planificación de Vacaciones - Portal del Empleado

Prototipo frontend para la planificación anual de vacaciones.

## Tecnología

- React
- TypeScript
- Vite
- Bootstrap 5
- React Router

## Alcance

Frontend únicamente.

No existe backend ni base de datos.

Los datos son simulados.
